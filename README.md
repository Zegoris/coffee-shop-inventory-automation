# Coffee Management System (CMS)

Программа для автоматизации учета складских запасов в кофейне.

## Основные возможности
- Учет остатков (молоко, зерно, сиропы).
- Автоматическое уведомление о дефиците товаров.
- Учет продаж и списание остатков.
- Хранение данных в формате JSON.

## Запуск
1. Установите Python 3.10 или выше.
2. Скачайте файлы проекта.
3. Запустите: `python main.py`

## Технологии
- Python 3
- JSON (хранилище данных)
- Модульная архитектура (OOP)
